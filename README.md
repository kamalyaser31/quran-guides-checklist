# قائمة فنيات الحصة الاحترافية (Quran Guides Checklist)

قائمة مرجعية (Checklist) تجمع فنيات الحصة التي تناولتها محاضرات مبادرة «صناعة النخبة» من Qur'an Guides، مقسّمة على مراحل الحصة ومساراتها، يرجع إليها المعلم قبل الحصة للتحضير وبعدها للتقويم.

## المحتوى

- [checklist.md](checklist.md): القائمة نفسها في ستة أقسام:
  1. قبل الحصة: التحضير.
  2. أثناء الحصة: مسارات الدرس (المفهوم، الحروف، الشرط، الأداء، الممارسة، علامة المصحف، الاستثناءات والعلة).
  3. أثناء الحصة: فنيات عرض المعلومة.
  4. أثناء الحصة: الفنيات العامة والدوافع.
  5. حصة التسميع والمراجعة.
  6. بعد الحصة: التقويم الذاتي.

لكل بند رقم ثابت، ووسم «أساسي» أو «عند الحاجة»، ورمز المحاضرة التي أُخذ منها، وتلميح قصير.

## طريقة الاستعمال

افتح `checklist.md` قبل الحصة، فاقرأ القسم الأول وبنود الأقسام التي تخص نوع حصتك. وبعد الحصة علِّم على ما استوفيته، ثم أتمّ القسم السادس.

## المرحلة القادمة

صفحة على GitHub Pages تحفظ في المتصفح قائمة الطلاب، وتسجّل لكل طالب حصصه بتاريخها والبنود المستوفاة في كل حصة. لم تُبنَ بعد.

## المساهمة

اقتراح بند جديد أو تعديل بند قائم يكون بقضية (Issue) تذكر نص البند ورمز المحاضرة التي يرجع إليها. ولا يتغير رقم بند قائم؛ فالبند المحذوف يُترك رقمه شاغراً.

سجل التغييرات في [CHANGELOG.md](CHANGELOG.md).

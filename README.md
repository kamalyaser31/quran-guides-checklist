# قائمة فنيات الحصة الاحترافية (Quran Guides Checklist)

قائمة مرجعية (Checklist) تجمع فنيات الحصة التي تناولتها محاضرات مبادرة «صناعة النخبة» من Qur'an Guides، مقسّمة على مراحل الحصة ومساراتها، يرجع إليها المعلم قبل الحصة للتحضير وبعدها للتقويم.

## المحتوى

- [checklist.md](checklist.md): القائمة نفسها في سبعة أقسام، لكل قسم نطاق واحد:
  1. كل حصة: التحضير.
  2. الدرس الجديد: تصميم الدرس.
  3. درس التجويد: مسارات الدرس (المفهوم، الحروف، الشرط، الأداء، الممارسة، المصحف، الاستثناءات والعلة).
  4. الدرس الجديد: عرض المعلومة.
  5. حصة التسميع والمراجعة.
  6. كل حصة: الفنيات العامة والدوافع.
  7. كل حصة: بعد الحصة.

لكل بند رقم ثابت، ووسم «أساسي» أو «عند الحاجة»، ورمز المحاضرة التي أُخذ منها، وتلميح قصير.

## صفحة التقييم

رابط الصفحة: [kamalyaser31.github.io/quran-guides-checklist](https://kamalyaser31.github.io/quran-guides-checklist/)

[index.html](index.html) صفحة واحدة تقرأ البنود من `checklist.md` مباشرة، فكل تعديل في الملف يظهر فيها دون خطوة أخرى:

1. اختر نوع الحصة: درس تجويد (الأقسام 1 و2 و3 و4 و6 و7)، أو حصة تسميع ومراجعة (الأقسام 1 و5 و6 و7)؛ فتظهر الأقسام التي تخصها وحدها.
2. علِّم على البنود التي استوفيتها.
3. اضغط «عرض التقييم»، فينتقل المؤشر إلى النتيجة: النسبة المئوية وتقديرها، ونسبة كل قسم، والبنود الأساسية التي فاتتك.
4. «تقييم جديد» يمسح العلامات. ولا تُحفظ العلامات بعد إغلاق الصفحة.

النسبة تُحسب على البنود الأساسية وحدها، وبنود «عند الحاجة» تُذكر عدداً منفصلاً. والتقدير: ممتاز من 90٪، وجيد جداً من 80٪، وجيد من 65٪، ومقبول من 50٪.

### التشغيل

الصفحة تقرأ الملف عبر الشبكة، فتُفتح من GitHub Pages أو من خادم محلي، لا بفتح `index.html` من القرص مباشرة:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح. وتحتاج الصفحة إلى الإنترنت لتحميل Tailwind وAlpine.js.

### الاختبار

`run_tests.py` يفتح الصفحة في Chromium ويتحقق من عدد البنود والنسبة والمسح، ويحتاج إلى `playwright` (في `requirements.txt`)، ويقبل مسار متصفح بديل بـ `--browser`.

## المساهمة

اقتراح بند جديد أو تعديل بند قائم يكون بقضية (Issue) تذكر نص البند ورمز المحاضرة التي يرجع إليها. وتُحفظ صيغة البند كما هي (`- [ ] **ID.** النص *(الوسم، المصدر)*` وتحته سطر `تلميح:`)، لأن الصفحة تقرأ البنود بها.

سجل التغييرات في [CHANGELOG.md](CHANGELOG.md).
